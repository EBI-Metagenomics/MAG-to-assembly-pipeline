# MAG-to-Assembly Linking Pipeline

This repository contains an Nextflow pipeline designed to map Metagenome-Assembled Genome (MAG) accessions to their corresponding primary metagenome assemblies. The pipeline uses metadata links retrieved through the ENA API and verifies matches by comparing contig checksums between MAGs and assemblies.

The pipeline consists of three consecutive processes:

1. **Creation of Input for the Main Script**

   Download lists of accessions from MGnify catalogs and ENA, merge them, remove redundancy, and exclude accessions that have been processed in previous runs of the pipeline. This step is skipped if running on user-provided input accessions.

2. **Mapping of Genomes to Assemblies**

   This process utilizes the ENA API to retrieve metadata of the input MAG accessions and using connections between genomes, samples and assemblies in the ENA data model identify accessions of putative primary assemblies.

3. **Validation of found assemblies using contig checksums**

   We treat MAG-assembly pair as valid only if all MAG's contigs are a subset of assembly's contigs. It's validated through comparason of hashes sets of contig sequences for each assembly and MAG. To compute contig checksum values FASTA files for all MAGs and assemblies are downloaded.

4. **Formatting of output files**

   MAG-assembly paires are merged into a single table, `Species_rep` and `Action` columns are added, updated [`processed_accessions_*.tsv`](`workflows/tests/data/processed_accessions.tsv`) and [`mag_to_assembly_mapping_*.tsv`](workflows/tests/data/mag_to_assembly_links.tsv) files are created.

## Requirements

- Singularity
- Nextflow

## Input Arguments

### Universal

- `--output_path`: Where to save output files. Default is `$PWD/results`
- `--batch_size`: Size of batches into which the list of input accessions is divided for parallel processing. Default is `250`

### Recurrent excecution on ENA and MGnify

- `--merge_with_results`: Earlier `mag_to_assembly_mapping_*.tsv` file generated by the pipeline in a previous run. An example is [`workflows/tests/data/mag_to_assembly_links.tsv`](workflows/tests/data/mag_to_assembly_links.tsv)
- `--skip_accessions`: List of the accessions `processed_accessions_*.tsv` that have been processed in previous runs of the pipeline. An example is [`workflows/tests/data/processed_accessions.tsv`](`workflows/tests/data/processed_accessions.tsv`)

**If these arguments are not specified, the pipeline will run inference of MAG-to-assembly links for all MAGs and bins deposited in the ENA and MGnify catalogues.**

### User-provided input

- `--accessions_list`: Custom list of accessions (one per line) to process instead of ones that are downloaded from ENA/MGnify
- `--catalogues_metadata`: Optional. Metadata table connecting input accession with their MGYG accessions and species representatives to include this information in the final table
- `--merge_with_results`: Optional. Earlier `mag_to_assembly_mapping_*.tsv` file. If provided, previously identified MAG-assembly pairs are included into the produced output. An example is [`workflows/tests/data/mag_to_assembly_links.tsv`](workflows/tests/data/mag_to_assembly_links.tsv)
- `--skip_accessions`: Optional. List of the accessions `processed_accessions_*.tsv` that have been processed in previous runs of the pipeline. An example is [`workflows/tests/data/processed_accessions.tsv`](`workflows/tests/data/processed_accessions.tsv`)

## Usage

### Locally with Docker on test dataset

```bash
nextflow run main.nf \
-profile local \
--accessions_list workflows/tests/data/input_accessions.tsv \
--skip_accessions workflows/tests/data/processed_accessions.tsv \
--merge_with_results workflows/tests/data/mag_to_assembly_links.tsv
```

### Slurm with Singularity

You can run the pipeline on SLURM with the following command:

```bash
nextflow run main.nf \
-profile codon_slurm main.nf \
--merge_with_results /path/to/file.tsv \
--skip_accessions /path/to/file.tsv
```

To launch a run on a test dataset `workflows/tests/data/`, use:

```bash
nextflow run main.nf \
-profile codon_slurm \
--accessions_list workflows/tests/data/input_accessions.tsv \
--skip_accessions workflows/tests/data/processed_accessions.tsv \
--merge_with_results workflows/tests/data/mag_to_assembly_links.tsv
```
